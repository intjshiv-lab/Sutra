Zero-Data-Loss App Update Protocol

How to safely ship new versions of Sutra (e.g. v1.1.0) without ever affecting user data:

1. Build new release binary: swift build -c release --package-path apps/sutra-macos 2. Package fresh disk image: bash scripts/package-dmg.sh 3. Upload new Sutra-Installer.dmg to GitHub Releases (or your website). 4. Customer Instruction: "Download new DMG, drag Sutra to Applications, click Replace."

Why this is safe: Sutra's database lives in ~/.sutra/sutra.db, and the activation license lives in ~/.sutra/.license. Neither file is touched when replacing /Applications/Sutra.app. All threads, notes, and licenses persist seamlessly.
