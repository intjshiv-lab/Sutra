01Cognitive Foundation: Eliminating Resumption Lag

Knowledge workers context-switch or face interruptions every 3 minutes and 5 seconds. Empirical research by Dr. Gloria Mark at UC Irvine establishes that it requires an average of 23 minutes and 15 seconds to recover deep cognitive focus after a significant interruption.

The largest component of this delay is Resumption Lag: the cognitive friction of re-discovering the right window, file line, browser tab, or remembering the precise next mental intention.

"सूत्रम् धारय, पुनः आरभस्व — Leave the thread where you'll need it again. Find it when you're back."

Sutra grounds itself on two foundational discoveries in cognitive psychology:

  • Altmann & Trafton (2002) — Memory for Goals: Working memory decays exponentially during an interruption. Placing an explicit, salient retrieval cue at the exact point of suspension reduces resumption lag by over 80%.
  • Gollwitzer — Implementation Intentions: Abstract to-dos fail under fatigue. Concrete "When Situation X occurs, execute Action Y" triggers make resumption near-automatic and involuntary.

The Sutra Emblem: The Needle & The Infinite Silk Thread

Satin Titanium Möbius & Gold Needle: Complete offline sovereignty. All data remains in your local SQLite WAL database (~/.sutra/sutra.db) with zero cloud telemetry.

Brushed Titanium Needle: A surgical cognitive anchor that pierces through distraction and holds your exact working state (file, line number, URL, intention).

Luminescent Terracotta Möbius Thread: The unbroken continuity of human working memory weaving seamlessly across apps for instant context recovery.

First-Run Gatekeeper Notice (Open-Source App)

Because Sutra is an independent open-source release distributed outside the Mac App Store, macOS Gatekeeper may present an initial prompt stating: "Apple cannot check it for malicious software / Move to Trash".

How to approve Sutra in System Settings:

  1. If macOS placed the app into Trash, open Trash, right-click Sutra.app, and select Put Back (or drag it back to /Applications).
  2. Open Apple Menu (ƒ) → System Settings → Privacy & Security.
  3. Scroll down to the Security section to locate: "Sutra.app was blocked from use because it is not from an identified developer."
  4. Click Open Anyway, authenticate with Touch ID or your Mac password, and click Open. macOS remembers this approval permanently.

Finder Shortcut: In /Applications, hold Control and click Sutra.app → select Open from the menu → click Open. Or in Terminal, run xattr -cr /Applications/Sutra.app.

06The 1-Click Closed-App Recovery Contract

Traditional todo lists only record abstract text. When you return days later, you must manually launch the browser, find the tab in history, open your IDE, and locate the code file.

The Closed-App Recovery Guarantee: Even if the target application was completely quit, the window dismissed, or the browser tab closed, Sutra restores your physical workspace with a single click.

How to Resume

  1. Click the Sutra logo icon in your macOS menu bar (or press ⌥ Option + S).
  2. Locate the thread under WAITING (Active Memory) or Scheduled for Today.
  3. Click ⚡ 1-Click Resume (Re-launch & Seek).

What Happens Under the Hood:

  • Web URL Anchors: Sutra calls the OS default handler or target browser to re-open the exact URL.
  • Code Editor Anchors: If VS Code or Cursor is detected, Sutra executes code -g <path>:<line>, opening the file and placing your cursor on the exact line you were reading.
  • Preview PDF Exact Page Anchors: If an active PDF was reading Page 14, Sutra re-activates Preview and seeks directly to the exact page anchor.
  • Quit Applications: Sutra uses NSWorkspace.shared.openApplication or open -a to spin up the closed process.

08The 6-Day Active Window & Auto-Dock Lifecycle

Sutra rejects the endless "backlog graveyard" where tasks accumulate until forgotten. Threads move through an automated, bi-directional lifecycle governed by a strict 6-day freshness window:

State Badge Behavior Available Actions
ACTIVE (Waiting) ACTIVE Working memory from the last 6 days, or threads older than 6 days with a future scheduled date. Counted in the menu bar. Resume • Snooze (4h) • Mark Done
DOCK (Later + Done) DOCK Long-term cognitive archive containing aged-out threads (> 6 days old without future schedule) and completed cues. 1-Click Resume / Undo to Active • Schedule Future Date

The Auto-Dock Rule

Any active cue older than 6 days that is not scheduled for a future day automatically transitions to Dock. If you assign a future date to any docked cue, it instantly reactivates back to Active. Nothing is ever lost or permanently deleted.

09Full Terminal Command Station Reference

Power users can manage Sutra entirely from the command line, integrate it into shell scripts, or bind it to Raycast/Alfred workflows.

Bundled CLI Location (DMG Install)

If you installed via DMG, the high-performance Rust CLI binary is located inside the application bundle:

/Applications/Sutra.app/Contents/Resources/sutra

To enable sutra system-wide in any terminal shell, create a symlink:

sudo ln -sf /Applications/Sutra.app/Contents/Resources/sutra /usr/local/bin/sutra

1. Quick Capture with Context Sniffing

# Capture with auto-sniffed frontmost application
sutra capture --title "Review paper section 3" --notes "Focus on equation 12"

# Capture a checklist
sutra capture --title "Deploy release" -c checklist

# Capture with manual URL override
sutra capture --title "Read Rust docs" --url "https://doc.rust-lang.org"

# Emit raw JSON output (ideal for automation scripts)
sutra capture --title "Scripted task" --json

2. Listing Threads

# List active waiting threads
sutra list

# List snoozed threads
sutra list --status later

# List completed threads
sutra list --status done

# Output as JSON
sutra list --json

3. 1-Click Resume

# Re-launch application, open file/URL, and seek line
sutra resume <THREAD_ID>

4. Snooze, Complete, and Undo

# Snooze for 4 hours
sutra snooze <THREAD_ID> --hours 4

# Mark as Done
sutra done <THREAD_ID>

# 1-Click Undo back to Waiting
sutra undo <THREAD_ID>

5. Sub-10ms Full-Text Search (SQLite FTS5)

# Search across all titles, notes, and tags in sub-2ms
sutra search "distributed consensus"

6. Desktop Context Sniffer Probe

# Inspect what Sutra detects on your active desktop right now
sutra sniff
